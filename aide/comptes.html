Comptes et mot de passe

Vigie Marchés est réservé aux personnes à qui l'administrateur a créé un compte. Cette page explique l'installation (une seule fois) et la gestion des comptes.

1. Installation 2. Sauvegarde automatique 3. Créer les comptes 4. Pour chaque utilisateur 5. Mot de passe oublié 6. Ce qui est protégé

1. Installation : créer le compte administrateur

À faire une seule fois, par l'administrateur, juste après la mise en ligne.

  1. Ouvrez dashboard.render.com et cliquez sur le service vigie-marches-dce.
  2. Menu de gauche Environment : repérez la variable VIGIE_CODE_INSTALLATION, cliquez sur l'œil pour l'afficher, puis copiez sa valeur.
  3. Ouvrez Vigie Marchés : l'écran « Installation » s'affiche.
  4. Collez le code, puis indiquez votre nom, votre adresse mail et un mot de passe d'au moins 10 caractères. Cliquez sur Créer le compte administrateur.

Le serveur gratuit s'endort après 15 minutes sans visite : la première connexion de la journée peut prendre jusqu'à une minute.

2. Sauvegarde automatique des comptes (recommandé)

Les comptes sont gardés dans la variable VIGIE_COMPTES du service Render (les mots de passe y sont chiffrés de façon irréversible). Pour que Vigie la mette à jour tout seul à chaque création de compte ou changement de mot de passe, donnez-lui une clé d'API Render (gratuite) :

  1. Sur Render, cliquez sur votre avatar en haut à droite, puis Account Settings, rubrique API Keys, bouton Create API Key. Nommez-la « Vigie » et copiez la clé.
  2. Revenez sur le service vigie-marches-dce, menu Environment. Remplissez la variable RENDER_API_KEY (ou ajoutez-la avec Add Environment Variable) avec la clé copiée.
  3. Cliquez sur Save, rebuild, and deploy. Attendez environ deux minutes.

Sans cette clé, chaque changement de compte affiche un texte à copier vous-même dans la variable VIGIE_COMPTES (même écran Environment, puis Save, rebuild, and deploy). Si vous l'oubliez, le changement est perdu au prochain redémarrage du serveur, y compris le compte administrateur créé à l'installation (il suffit alors de refaire l'installation).

Avec la clé, le serveur redémarre de lui-même une minute après chaque changement de compte, pour l'enregistrer. Vigie reste utilisable pendant ce temps.

3. Créer les comptes des utilisateurs

  1. Dans Vigie, cliquez sur l'engrenage ⚙ en haut à droite, puis Gérer les comptes.
  2. Saisissez le nom et l'adresse mail de la personne, puis Créer le compte. Cochez « Administrateur » seulement si elle doit pouvoir gérer les comptes.
  3. Vigie affiche un mot de passe provisoire : transmettez-le à la personne (par téléphone ou SMS de préférence). Il ne sera plus affiché ensuite.

Dans la même fenêtre : Nouveau mot de passe (mot de passe oublié : un nouveau provisoire est créé et l'ancien ne marche plus) et Supprimer (la personne est déconnectée aussitôt de tous ses appareils).

4. Pour chaque utilisateur

  1. Ouvrez Vigie, saisissez votre adresse mail et le mot de passe provisoire reçu.
  2. Vigie demande aussitôt de choisir votre propre mot de passe (10 caractères minimum).
  3. Vous restez connecté 30 jours sur ce navigateur. Engrenage ⚙ en haut à droite : Changer mon mot de passe, Se déconnecter, et vos connexions (drive, alertes mail).

Retrouver ses marchés et réglages sur tous ses appareils (PC, téléphone)

  1. Sur chaque appareil, connectez-vous à Vigie, puis appuyez sur l'engrenage ⚙ en haut à droite, Mon drive, et connectez-vous une fois à Microsoft.
  2. Vigie range alors une copie de vos marchés suivis, statuts, filtres, dossier OneDrive et réglages des alertes mail dans votre OneDrive (dossier « Applications / Vigie Marchés »), et la relit sur vos autres appareils.
  3. Le dossier OneDrive des réponses est donc le même sur le PC et sur le téléphone : vous ne collez son lien qu'une fois.
  4. Le mot de passe de la messagerie (case « Se souvenir du mot de passe ») y est gardé chiffré : seul le serveur Vigie peut le relire, pour votre compte uniquement.

Sans connexion Microsoft sur un appareil, ses données restent seulement dans son navigateur, comme avant.

5. Mot de passe oublié

Sur l'écran de connexion, le lien Mot de passe oublié ? envoie à l'adresse saisie un mail avec un lien pour créer un nouveau mot de passe (valable 1 heure, une seule fois), si cette adresse a un compte. Pour que Vigie puisse envoyer ce mail, l'administrateur fait une fois :

  1. Créez un compte gratuit sur brevo.com (300 mails par jour offerts, sans carte bancaire).
  2. Dans Brevo, menu Senders, Domains & Dedicated IPs (Expéditeurs), ajoutez l'adresse qui enverra les mails (par exemple la vôtre) et validez-la avec le code reçu.
  3. Dans Brevo, menu SMTP & API, onglet API Keys, bouton Generate a new API key, nommez-la « Vigie » et copiez la clé (elle commence par xkeysib-).
  4. Sur Render, service vigie-marches-dce, Environment : ajoutez BREVO_API_KEY (la clé) et MAIL_EXPEDITEUR (l'adresse validée à l'étape 2), puis Save, rebuild, and deploy.

Tant que ce n'est pas fait, « Mot de passe oublié » indique de demander un nouveau mot de passe à l'administrateur (Gérer les comptes, bouton Nouveau mot de passe).

6. Ce qui est protégé

  • Le serveur vigie-marches-dce (DCE, RC, CAPTCHA, analyse du RC, dépôt dans le drive, lecture des alertes mail, ajout par lien) ne répond plus qu'aux utilisateurs connectés, et seulement depuis le site Vigie.
  • Le site affiche l'écran de connexion tant qu'on n'est pas connecté. Le code de la page reste public (il est sur GitHub), mais il ne contient aucune donnée ni aucun accès.
  • Après 8 mauvais mots de passe en 15 minutes, les essais sont bloqués 15 minutes.
  • Changer son mot de passe déconnecte ses autres appareils.
