Connecter son drive et sa messagerie à Vigie Marchés

Procédure pas à pas pour chaque utilisateur. Chacun connecte son propre drive et sa propre boîte mail : rien n'est partagé avec les autres utilisateurs.

Sommaire : 1. Connecter son drive 2. Connecter sa messagerie 3. Sécurité 4. Administrateur de Vigie

1. Connecter son drive (dossiers de réponse)

Quand vous cliquez J'y réponds sur un marché, Vigie crée le dossier de la consultation dans votre drive (DCE dézippé, sous-dossiers Analyse, Candidature, Offre, Contrôle) et tient à jour le tableau « 00_Suivi des marchés.xlsx ».

En haut de Vigie, cliquez ☁ Connecter mon drive. Choisissez ensuite le cas qui vous correspond.

A. OneDrive ou SharePoint (Microsoft 365) — fonctionne aussi sur téléphone et tablette

  1. Dans OneDrive (onedrive.com ou l'explorateur Windows), créez un dossier pour vos réponses, par exemple Appels d'offres.
  2. Faites un clic droit sur ce dossier, puis Partager › Copier le lien. Le lien n'a pas besoin d'être ouvert à d'autres personnes : il sert seulement à indiquer le dossier à Vigie.
  3. Dans Vigie, fenêtre « Connecter mon drive », cliquez Se connecter à Microsoft et choisissez votre compte (professionnel ou personnel).
  4. Microsoft vous demande d'autoriser Vigie à accéder à vos fichiers : acceptez.
  5. Collez le lien du dossier dans la case prévue puis cliquez Enregistrer ce dossier. Le bouton du haut affiche alors « OneDrive · nom du dossier » avec un point vert.
À refaire une fois sur chaque appareil (PC, téléphone, tablette) : le réglage est gardé dans le navigateur de l'appareil.

B. Google Drive, Dropbox, iCloud Drive ou serveur de l'entreprise — sur PC

  1. Installez l'application de votre drive sur le PC : Google Drive pour ordinateur, Dropbox, iCloud pour Windows… et connectez-vous. Votre drive apparaît comme un dossier dans l'explorateur Windows (par exemple G:\Mon Drive).
  2. Créez dans ce drive le dossier des réponses, par exemple Appels d'offres.
  3. Ouvrez Vigie avec Google Chrome ou Microsoft Edge sur le PC.
  4. Fenêtre « Connecter mon drive » : cliquez Choisir le dossier du PC, sélectionnez le dossier des réponses, puis acceptez quand le navigateur demande l'autorisation de modifier les fichiers.
  5. Vigie écrit dans ce dossier ; l'application du drive l'envoie en ligne toute seule.
Le navigateur peut redemander l'autorisation d'accès au dossier après un redémarrage : cliquez simplement « Autoriser ».

2. Connecter sa messagerie (import des alertes des plateformes)

Inscrivez-vous d'abord aux alertes mail des plateformes (BOAMP, PLACE, Maximilien, AWS-Achat, achatpublic, e-marchespublics…) avec vos mots-clés. Ensuite, en haut de Vigie, cliquez ✉ Importer les alertes mail : Vigie retrouve dans vos mails les consultations annoncées, vous cochez celles qui vous intéressent, et elles s'ajoutent à la recherche avec leurs boutons RC, DCE et statuts.

Choisissez la période (depuis le dernier import, 7 jours, 30 jours…), puis le cas qui vous correspond.

A. Outlook, Hotmail, Live ou Microsoft 365

  1. Cliquez Se connecter et chercher dans Outlook.
  2. Choisissez votre compte Microsoft. La première fois, Microsoft demande d'autoriser Vigie à lire vos mails : acceptez (lecture seule, Vigie ne peut ni envoyer ni supprimer).
  3. Vigie parcourt les mails de la période, garde les alertes des plateformes et affiche les consultations trouvées.
Si votre entreprise bloque l'autorisation (« approbation de l'administrateur requise »), demandez à votre informaticien d'approuver l'application « Vigie Marchés », ou utilisez le copier-coller (cas D).

B. Gmail

Google demande un mot de passe d'application : un code de 16 lettres réservé à Vigie, différent de votre mot de passe Gmail et que vous pouvez supprimer à tout moment.

  1. Activez la validation en deux étapes si ce n'est pas déjà fait : myaccount.google.com › Sécurité › Validation en deux étapes.
  2. Ouvrez myaccount.google.com/apppasswords, tapez le nom Vigie Marchés et cliquez Créer.
  3. Copiez le code de 16 lettres affiché (les espaces ne comptent pas).
  4. Vérifiez que l'accès IMAP est actif : Gmail › ⚙ Paramètres › Voir tous les paramètres › Transfert et POP/IMAP › « Activer IMAP » (déjà actif sur les comptes récents).
  5. Dans Vigie, bloc « Gmail et autres messageries » : choisissez Gmail, tapez votre adresse Gmail, collez le code de 16 lettres, puis cliquez Chercher dans cette boîte.
  6. Cochez « Se souvenir du mot de passe sur cet appareil » pour ne pas le retaper à chaque import (à éviter sur un ordinateur partagé).
Vigie lit aussi les alertes rangées par un filtre Gmail dans un libellé : il cherche dans « Tous les messages ».

D. Sans connexion : copier-coller d'un mail

  1. Ouvrez le mail d'alerte dans votre messagerie, sélectionnez tout (Ctrl + A) puis copiez (Ctrl + C).
  2. Dans Vigie, cliquez dans la zone « Collez ici le mail d'alerte » puis collez (Ctrl + V).
  3. Vous pouvez aussi déposer dans cette zone des mails enregistrés au format .eml (Thunderbird, Gmail › ⋮ › Télécharger le message).

Ensuite, pour chaque import

  1. Vigie affiche la liste des consultations trouvées, avec la plateforme et le mail d'origine. Celles déjà présentes dans Vigie sont grisées.
  2. Décochez celles qui ne vous intéressent pas (Vigie ne vous les reproposera plus), puis cliquez Ajouter N marchés.
  3. Vigie lit chaque consultation (avis BOAMP ou page de la plateforme). Les marchés s'affichent en tête de la recherche. Si une information manque, la ligne l'indique : cliquez Modifier sur l'encart du marché pour la compléter.

Import automatique chaque matin

  1. Dans la fenêtre d'import, laissez cochée la case Importer automatiquement chaque matin et faites un premier import (Outlook, ou Gmail et autres avec Se souvenir du mot de passe sur cet appareil).
  2. Ensuite, à la première ouverture de Vigie de la journée (à partir de 6 h), Vigie relit la boîte sans rien vous demander et ajoute les nouveaux marchés.
  3. Un résumé s'affiche en haut de la page : d'abord les marchés qui correspondent à vos filtres de recherche, puis les autres. Le bouton Retirer enlève un marché et Vigie ne le reproposera plus.
  4. Si un onglet Vigie reste ouvert la nuit, l'import part tout seul le matin. Vigie fermé, rien ne se passe : l'import se fait à la prochaine ouverture.

3. Sécurité et confidentialité

  • Outlook / Microsoft 365 : vos mails sont lus directement par votre navigateur auprès de Microsoft. Ils ne passent pas par Vigie.
  • Gmail et IMAP : le serveur Vigie se connecte à votre boîte en lecture seule le temps de l'import, puis se déconnecte. Il ne garde ni votre mot de passe, ni vos mails, et ne les écrit dans aucun journal. Il ne renvoie que les mails des plateformes de marchés publics.
  • Vos connexions (compte Microsoft, mot de passe si « se souvenir » est coché, dossier choisi) sont gardées uniquement dans le navigateur de votre appareil. Les autres utilisateurs de Vigie n'y ont pas accès.
  • Pour tout couper : supprimez le mot de passe d'application (Google, Yahoo, Apple), ou retirez l'application « Vigie Marchés » de votre compte Microsoft (myapps.microsoft.com ou account.live.com/consent/Manage), et videz les données du site dans le navigateur.

4. Pour l'administrateur de Vigie (une seule fois)

Par défaut, la connexion Microsoft n'accepte que les comptes de l'entreprise qui a déclaré l'application. Pour que chaque client se connecte avec son propre compte Microsoft (professionnel ou personnel) :

  1. Ouvrez entra.microsoft.com avec le compte qui a déclaré l'application, puis Applications › Inscriptions d'applications › Vigie Marchés.
  2. Menu Authentification › « Types de comptes pris en charge » : choisissez Comptes dans un annuaire organisationnel (tout locataire Microsoft Entra ID) et comptes Microsoft personnels, puis Enregistrer. (Si l'option est grisée, passez par le menu Manifeste : "signInAudience": "AzureADandPersonalMicrosoftAccount".)
  3. Menu Autorisations des API › Ajouter une autorisation › Microsoft Graph › Autorisations déléguées : cochez Mail.Read et Files.ReadWrite.All (à côté de Files.ReadWrite et User.Read déjà présentes). Files.ReadWrite.All sert aux dossiers rangés dans un site SharePoint d'équipe (lien en …sharepoint.com/:f:/s/…).
  4. Prévenez le développeur de Vigie : il active alors la connexion « tous comptes » dans l'application (réglage MS_MULTI).
Réglage fait le 22/11/2026 : la connexion Microsoft accepte tous les comptes (professionnels et personnels). Si une entreprise cliente affiche « Approbation de l'administrateur requise », son administrateur approuve « Vigie Marchés » une fois.
